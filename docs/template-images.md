# 템플릿 예시 사진

2026-10-03 내장 `image_gen.imagegen` 도구로 22개의 개별 사진을 생성했다. CLI나 별도 API 키는 사용하지 않았다. 실제 업체 사진·로고를 복제하지 않았고, 모든 장면·인물은 가상의 예시다. 사용한 최종 프롬프트와 원본 파일 이름, 배포 파일 경로는 [프롬프트 기록](template-image-prompts.json)에 있다. 원본은 Codex generated_images에 보존되며 배포는 저장소의 WebP만 사용한다.

| 업종        | 제작 장면                                |
| ----------- | ---------------------------------------- |
| 음식점      | 삼겹살, 김치찌개, 계절 한상              |
| 카페        | 라떼와 공간, 베이커리, 계절 차           |
| 미용실      | 살롱 공간, 커트, 컬러, 헤어 케어         |
| 헬스장      | 시설, 개인 트레이닝, 스트레칭 클래스     |
| 마트        | 과일, 채소, 생활용품                     |
| 전문 사무실 | 상담실, 업무 책상, 상담 장면             |
| 방문 안내형 | 접수·대기 공간, 상담실, 방문 안내 접수대 |

## 적용과 교체

- `public/template-images/`: 1440×960 WebP와 640px 폭의 `-small.webp`. Sharp로 리사이즈·압축만 했으며 장면을 합성하거나 편집하지 않았다. 총 44파일 약 3.36 MiB.
- `templates/catalog/images.ts`: 대표 사진, 항목별 사진, 사진 설명. 파일 교체 시 큰 파일과 작은 파일 모두 교체한다.
- `TemplateArt.tsx`: 브라우저 srcset으로 크기를 선택하고 화면 밖 사진은 지연 로딩한다. 확대 모달은 큰 원본을 표시한다.
- `designs/`: 레이아웃마다 대표 사진 배치가 다르다. 음식 메뉴·카페 컬렉션·미용 작업·운동 프로그램·마트 상품에도 항목별 사진을 연결한다.
- 업종 콘텐츠 선택이 사진 세트를 결정하므로 음식점 내용을 다른 디자인에 적용해도 음식 사진이 나온다. 카테고리 필터 후에도 항목의 원래 사진을 유지한다.
- 갤러리 설명은 사진 장면과 맞추고 확대·이전·다음에도 동일한 사진을 사용한다.

고객 관리·게시 템플릿과 데이터는 변경하지 않았다. 고객 업로드 사진은 기존 비공개 Storage를 계속 사용한다. AI 예시 사진은 실제 고객 사진이나 실적·자격의 증거로 표시하지 않는다. 담당자 소개 옵션은 실제 인물 사진을 받기 전까지 기존 소개 자리 표시를 유지한다.
