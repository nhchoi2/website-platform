# 기본 포함과 유료 추가 구분

2026-10-03 기준. 기본 포함은 홈페이지 전체가 무료라는 뜻이 아니라 기본 원페이지 제작비 390,000원(VAT 포함)에 추가 비용 없이 포함되는 범위다. 운영·관리 월 33,000원부터와 도메인 비용은 별개다. 유료 옵션별 금액은 아직 확정하지 않았으며 상담 후 견적한다.

## 기본 포함

- 매장 소개, 주소, 연락처, 운영시간·휴무·주차, 기본 메뉴·상품·서비스와 가격.
- 필요 시 가격 비교표, 담당자 소개, 요일별 시간표, 이용 절차, FAQ, 맨 위로 버튼을 추가 비용 없이 선택.
- 모바일 반응형, 기본 검색 제목·설명, 정해진 메뉴 위치, 모바일 펼친 메뉴/메뉴 버튼 선택.
- 제공된 로고와 브라우저 탭 아이콘 적용은 기본 제작 범위로 권장한다. 신규 로고 디자인은 별도 제작이다. **현재 미리보기에는 파일 등록 기능을 구현하지 않았다.** 고객 자료 수집·비공개 저장·검수·게시·사이트별 탭 아이콘 연동은 후속 구현이 필요하다.
- 기본 사진을 표시하는 것은 포함이다. 확대·넘기기 등의 추가 갤러리 기능은 유료로 구분한다.
- 기본 방문 안내의 일반 지도·예약·카카오 링크와 추가 고정 플로팅 버튼은 서로 다른 작업이다. 일반 링크 적용 자체를 API 연동으로 설명하지 않는다.

## 현재 선택·시연 가능한 유료 추가

- 사진 확대 갤러리, 공지·소식 게시판 시연, 상단 안내 배너.
- 상담·예약·플레이스·카카오 플로팅 버튼.
- 3·4페이지 확장은 별도 견적. 기본 포함 항목만 선택하면 추가 비용 견적 대상으로 표시하지 않는다.

공지 게시판은 현재 목록·펼치기 동작을 보여주는 정적 시연이다. 실제 글 등록·편집·검색·첨부·고객별 저장 기능이 구현된 게시판으로 보고하지 않는다. 새 업종 7종의 미리보기 옵션은 기존 고객 DB 편집·검수·게시 기능에 자동으로 추가되지 않는다.

## 별도 개발을 권장하는 기술 옵션 — 아직 선택·연동하지 않음

## 지도 요금 근거

조회일 2026-10-03. 지도 ‘설치 작업비’와 외부 업체 ‘API 사용료’를 구분한다. 무료 구간이 있어도 전체 서비스 무조건 무료라고 표시하지 않는다.

- [Google Maps Embed API usage and billing](https://developers.google.com/maps/documentation/embed/usage-and-billing): Embed API는 사용료 없이 이용 가능. JavaScript Maps·Places·경로 API와는 다른 제품이다.
- [Google Maps Embed API quickstart](https://developers.google.com/maps/documentation/embed/quickstart): API 키와 결제 계정 설정이 필요할 수 있다.
- [NAVER Cloud 가격 안내](https://m.ncloud.com/charge/price/ko), [Maps 무료 이용량 FAQ](https://www.ncloud.com/support/faq/all/2828): 지도 제품의 무료 이용량·계정 조건·초과 과금·한도 설정을 확인한다. 실제 고객 연결 전 최신 요금을 다시 확인한다.
- [Google 모바일 사이트 안내](https://developers.google.com/search/docs/crawling-indexing/mobile/mobile-sites-mobile-first-indexing): 반응형 디자인을 권장한다. 기본 반응형 포함은 이 서비스의 상품 구성 제안이며 Google이 무료 제공을 요구하는 것은 아니다.

## 주요 수정 위치

`templates/catalog/options.ts`의 `cost`가 기본 포함/유료의 공통 기준이다. 상세 화면과 별도 미리보기에서 같은 분류를 사용한다. 메뉴 배치와 모바일 메뉴 선택은 URL의 `nav`·`mobileNav`로 보존하며 허용 값만 받아들인다. 화면 코드는 `TemplateHeader.tsx`, 기본 스타일은 `catalog.css`다.
