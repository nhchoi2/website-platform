## 디자인과 업종 분리

7종은 서로 다른 JSX 구성이다. 업종은 추천 필터와 예시 콘텐츠에 사용한다. 상세보기에서 어떤 업종의 내용도 선택할 수 있다. `demoContent()`가 브랜드·메뉴·서비스·그림만 교체하며 디자인 ID·색상·구조는 유지한다. 예를 들어 음식점은 테이블·화보·상품 안내형을 추천받지만 아틀리에나 파트너도 선택할 수 있다.

## 공통 옵션

사진 갤러리(모달·이전/다음), 가격 비교표, 담당자 소개, 요일별 시간표, 펼치는 공지, 이용 절차를 추가했다. 기존 FAQ·배너·플로팅 외부 링크도 유지한다. 콘텐츠 옵션을 체크하면 미리보기가 해당 영역으로 이동하고, 추가한 콘텐츠 바로보기 버튼으로 다시 찾을 수 있다. 선택은 URL에 기록되며 새로고침과 내부 페이지 이동 후 유지된다.

업종별 사진 22장은 내장 이미지 생성 도구로 별도 제작한 AI 예시이며 실제 고객의 공간·직원·상품 사진이 아니다. 대표 화면·메뉴·서비스·상품·갤러리에 연결했고, 갤러리는 서로 다른 사진을 확대한다. 실제 제작에는 고객이 제공하거나 사용 권한이 확인된 사진이 필요하다.

## 검증과 현재 범위

22개 테스트, 타입 검사, 린트, 프로덕션 빌드, 분리된 임시 로컬 DB 기반 수용 검사를 통과했다. 7개 디자인의 원페이지와 3·4페이지 경로, 위험한 링크 차단, 고객 도메인 격리, 다른 업종 적용, 옵션 유지가 포함된다. 브라우저에서 추천 필터 복귀, 갤러리·시간표·분류·내부 페이지 이동·새로고침 유지, 375px 뷰포트의 가로 넘침을 확인했다.

제작 상담용 미리보기 구현이다. 고객의 초안·승인·공개 데이터에 새 디자인을 연결하지 않았다. 현재 고객 관리와 실제 게시까지 연결된 디자인은 기존 혜화 1종이다. 추가 가격은 확정 전이므로 임의로 합산하지 않는다. 문의도 DB 접수나 자동 발송이 아닌 사용자가 보내는 이메일이다.
