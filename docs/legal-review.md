# 법적 문서 확인 기록

확인일: 2026-10-03 (한국 시간).

## 이번 반영

- `/terms`: 쉬운 요약, 문서 목차, 제작 계약 전 확인 목록. 기존 계정·검수·게시·비용 조건은 유지.
- `/privacy`: 쉬운 요약, 목차, 계정 수집 항목과 외부 서비스 표. 실제 처리 위치나 보유기간을 추정하지 않음.
- 이번 변경은 기존 조건의 설명과 화면 구성을 개선한 것. 적용 조건·수집 범위·동의 버전을 변경하지 않음. 기존 동의를 새로운 실질적 조건에 대한 동의로 취급하지 않음.
- `LEGAL_PUBLISHED`, 사업자 환경 변수, DB의 동의 이력 및 외부 계정 설정은 변경하지 않음. 코드 반영을 법적 검토 완료나 운영 설정 완료로 보고하지 않음.

## 참고 자료

- [네이버 개인정보 처리방침](https://policy.naver.com/policy/privacy.html): 쉬운 용어, 목차, 수집·목적·위탁·삭제·권리 구분.
- [아임웹 이용약관](https://imweb.me/terms): 제작·운영 서비스의 계정과 콘텐츠 등 확인 범위.
- [아임웹 개인정보 처리방침](https://imweb.me/privacy): 위탁 및 국외이전 안내 범위.

다른 회사의 조문을 복사하지 않았다. 참고 문서는 우리 서비스의 법적 적합성을 보증하지 않는다.

## 운영자가 확정할 사항

1. 운영 법적 주체, 사업장 주소, 사업자등록번호, 개인정보 담당자. `lib/server/legal.ts` 환경 변수와 실제 표시 값 확인.
2. 계정·연락처·동의 이력·사이트 버전·이미지·접속 기록별 실제 보유기간, 삭제 절차, 백업에 남는 기간. 단순 계정 삭제가 이미지·과거 버전까지 삭제한다는 보장을 하지 않음.
3. Supabase, Vercel, Resend, Google의 실제 계약 주체, 처리/접근 국가, 항목, 목적, 이전 방식과 시점, 보유기간, 거부 및 권리 행사 방법. 서울 DB 리전만으로 국외이전이 없다고 판단하지 않음.
4. 제작 범위, 일정, 수정 횟수, 계약 종료 시 인계, 관리 범위, 취소·환불 기준. 현재 사이트 가격은 기본 범위의 시작 가격이며 견적·계약으로 확정.
5. 실질적인 약관/처리 조건 변경 시 적용일·공지·필요한 동의 판단, `lib/legal.ts` 버전과 DB 허용 버전의 재현 가능한 마이그레이션을 함께 진행. 기존 동의 문서 스냅샷 보관.
6. 고객 사이트에 문의폼 등을 도입할 경우 고객의 개인정보 처리 역할과 서비스의 위탁 역할을 구분하고 별도 안내·계약 검토. 현재 시연 게시판을 실제 수집 기능으로 표현하지 않음.

확인되지 않은 사실을 공개 고지로 확정하지 말 것. 필요한 법률 검토 후 조건을 확정하고 공개 여부를 변경한다.
